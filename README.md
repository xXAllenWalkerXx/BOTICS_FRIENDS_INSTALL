# BOTICS_FRIENDS installer

Публичные установочные скрипты BOTICS_FRIENDS. Репозиторий не содержит токены,
пароли и исходный код приватного проекта.

## Новый 3x-ui узел

Скрипт предназначен для чистого сервера Ubuntu/Debian. Он устанавливает 3x-ui
`v3.8.5`, закрепляет Xray-core `v26.7.28`, получает HTTPS-сертификат для домена,
настраивает UFW и создаёт API token для подключения узла к мастер-панели.

### 1. Подготовьте сервер и DNS

1. Создайте поддомен, например `node2.example.com`.
2. Создайте для него обычную DNS A-запись на публичный IPv4 нового сервера.
3. Если DNS-провайдер поддерживает проксирование, на время установки отключите
   его: запись должна указывать непосредственно на сервер.
4. Во внешнем firewall хостинга разрешите TCP-порты `22`, `80` и порт панели
   `2053`. Разрешите TCP/UDP-порт будущего inbound, например `443`.
5. Дождитесь обновления DNS. Проверить можно командой
   `dig +short node2.example.com` — она должна вернуть IP нового сервера.

TCP `80` нужен для выпуска и автоматического продления сертификата. Порт панели
лучше разрешить только с публичного IP мастер-сервера.

### 2. Запустите установку

Подключитесь к новому серверу по SSH и выполните команды, предварительно заменив:

- `node2.example.com` — поддомен нового узла;
- `203.0.113.10` — публичный IP сервера с мастер-панелью;
- `443` — порт будущего inbound; несколько портов указываются через запятую.

```bash
curl -fsSL https://raw.githubusercontent.com/xXAllenWalkerXx/BOTICS_FRIENDS_INSTALL/main/xui-node.sh -o /tmp/botics-xui-node.sh
sudo env BOTICS_XUI_DOMAIN=node2.example.com BOTICS_MASTER_IP=203.0.113.10 BOTICS_INBOUND_PORTS=443 bash /tmp/botics-xui-node.sh
```

Скрипт остановится до установки, если A-запись ещё не существует или ведёт на
другой сервер.

### 3. Получите реквизиты узла

После успешной установки выполните:

```bash
sudo cat /etc/x-ui/install-result.env
sudo systemctl status x-ui --no-pager
```

Файл `install-result.env` доступен только root и содержит секреты. Не отправляйте
его целиком в чат и не сохраняйте в Git. Для формы **Узлы 3x-ui** в BOTICS нужны:

| Поле BOTICS | Значение установщика |
| --- | --- |
| Протокол панели | `https` |
| Домен или IP | домен из `XUI_ACCESS_URL`, без `https://`, порта и пути |
| Порт панели | `XUI_PANEL_PORT` |
| Base path | `XUI_WEB_BASE_PATH` |
| API token | `XUI_API_TOKEN` |

В админке BOTICS нажмите **Проверить и добавить в мастер**. Статус «Онлайн»
означает, что мастер-панель видит API нового сервера.

### 4. Создайте inbound на новом узле

Добавление узла не копирует существующие inbound автоматически. В мастер-панели
3x-ui:

1. Откройте **Inbounds**.
2. У существующего рабочего inbound нажмите **Клонировать**.
3. В поле привязки/панели выберите новый узел.
4. Сохраните клон и убедитесь, что он включён.
5. Запомните ID клона, отображаемый в мастер-панели.

Одинаковый inbound-порт, например `443`, можно использовать на разных физических
серверах. Он должен быть открыт во внешнем firewall хостинга и в UFW; именно для
этого он передаётся через `BOTICS_INBOUND_PORTS`.

### 5. Подключите inbound к подпискам BOTICS

1. В BOTICS откройте **Узлы 3x-ui**.
2. Введите master-side ID нового inbound и сохраните его как цель подписок.
3. Новые подписки будут сразу создаваться на этом inbound.
4. Для существующих активных клиентов нажимайте **Добавить пакет**. За один
   запуск обрабатываются 10 подписок; UUID, `sub_id` и ссылка сохраняются.
5. Повторяйте операцию, пока не появится статус **Все подключены**.

### Настройки скрипта

- `BOTICS_XUI_DOMAIN=node.example.com` — домен узла, обязателен по умолчанию;
- `BOTICS_MASTER_IP=203.0.113.10` — открыть API панели только для IP мастера;
- `BOTICS_INBOUND_PORTS=443,8443` — открыть TCP и UDP inbound-порты;
- `BOTICS_SSH_PORT=22` — SSH-порт, который будет разрешён до включения UFW;
- `BOTICS_PANEL_PORT=2053` — порт панели при первой установке;
- `BOTICS_XUI_SSL_MODE=domain|ip|none` — режим HTTPS, по умолчанию `domain`;
- `BOTICS_ENABLE_UFW=0` — не изменять UFW;
- `BOTICS_XUI_VERSION=v3.8.5` — версия 3x-ui;
- `BOTICS_XRAY_VERSION=v26.7.28` — версия Xray-core.

Повторный запуск не переустанавливает 3x-ui, но повторно закрепляет Xray-core и
добавляет недостающие правила UFW. После обновления 3x-ui повторно запустите
скрипт: обновление панели может заменить Xray-core на комплектную версию.

### Быстрая диагностика

```bash
sudo systemctl status x-ui --no-pager
sudo journalctl -u x-ui -n 100 --no-pager
sudo ufw status numbered
curl -I https://node2.example.com:2053/
```

- Нет сертификата: проверьте A-запись и доступность TCP `80` извне.
- Узел не добавляется: проверьте домен, порт, base path и API token.
- Узел онлайн, но inbound отсутствует: клонируйте рабочий inbound через
  мастер-панель и привяжите к новому узлу.
- Клиенты не видят новый сервер: добавьте ID inbound в цели подписок и выполните
  **Добавить пакет** для существующих подписок.
